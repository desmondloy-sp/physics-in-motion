Multi-Stage 1D Kinematics Simulation

How to use
1. Choose 2 or 3 stages, and set initial position and velocity.
2. For each stage, pick constant v or constant a, set duration and acceleration.
3. Click Start to see the continuous motion and graphs; Pause or Reset as needed.

Drag the cart to set where it starts; drag the tip of the green arrow to set its starting velocity. Drag across any graph to replay a moment. On the graphs, a dotted line marks each change of stage.
The track's scale grows to fit the motion. All the stages run one after another as one continuous motion: each stage starts with the position and velocity the previous one ended with.
