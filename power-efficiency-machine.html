Power and Efficiency of a Lifting Machine

Work done on the load so far = GPE gained = mgh
—
Useful power output = work done ÷ time
—
Power input = output ÷ efficiency
—
Power wasted (heat, sound)
—
Lifting power right now = mgv
—
Run the motor — or grab the load and lift it yourself. Lift faster and see your power go up.
  • Efficiency = useful energy output ÷ total energy input × 100%, which is the same as useful power output ÷ power input × 100%.
  • The motor must take in more energy than the load gains. The difference is wasted, mostly as heat and sound.
  • Power is the rate of doing work, P = W/t. The same lift done in less time needs more power.
  • g = 10 m s-2.
